# Data Directory

This directory stores datasets for the **Personal Expense Tracker** project.

## Files
- expenses.csv: Synthetic dataset containing 180 realistic personal expense transactions spanning the year 2025.
- expenses.db: Local SQLite database storing cleaned transaction records.

## Synthetic Data Notice
All transactions, descriptions, and figures in this folder are synthetically generated for demonstration and educational portfolio purposes. No real banking or personal financial data is stored here.
